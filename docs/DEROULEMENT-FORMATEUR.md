## Méthode de démonstration

1. Ouvrir le cas fictif « responsabilité humaine et IA » dans Démonstrations.
2. Charger l’exemple : l’atelier annonce une confirmation avant de remplacer les saisies courantes.
3. Montrer la note S09, les champs d’une fiche et l’aperçu de droite.
4. Faire une erreur volontaire (par exemple une promesse impossible) ; demander sa correction.
5. Télécharger la V1, la grille, le prompt et la preuve. Vérifier les fichiers dans Téléchargements.
6. Rappeler que l’IA n’est pas connectée et ne décide pas pour l’humain.

## Préparation technique

- Tester l’aperçu autonome la veille, puis le projet Vite local si disponible.
- Pour la projection, section Présentation → Plein écran, flèches ← → pour naviguer, bouton Notes pour l’animateur.
- Présenter un exemple fictif sans données personnelles.
- Utiliser Chrome, Edge ou Firefox récent ; garder VS Code accessible.
- Contrôler l’accès à `https://github.com/elhisse-CLPrepas/atelier-seance-09-ln-ia`.
- Vérifier les boutons d'export et le classement des fichiers.

## Critères pédagogiques de sortie

Le candidat peut expliquer la différence note/fiche, décrire le premier livrable, produire une V1, identifier des risques, justifier au moins un contrôle humain et classer une trace portfolio. La vérification de ces acquis dépend du formateur.
