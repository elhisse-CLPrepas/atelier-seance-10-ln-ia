## 1. Résumé du projet en 5 lignes

Le projet consiste à créer une ressource pédagogique sur le rôle de l'humain dans la production avec l'IA.  
Cette ressource s'adresse aux candidats du Challenge 100 Jours, aux formateurs et aux professionnels débutants.  
Elle rappelle que l'IA peut aider à produire, mais qu'elle ne remplace pas la réflexion humaine.  
Elle organise le rôle humain autour de cinq responsabilités : piloter, contrôler, corriger, valider et assumer.  
Elle servira de base pour un guide pratique simple, utilisable en séance ou en accompagnement candidat.  

## 2. Titre provisoire du guide pratique

```text
Guide pratique - Garder le contrôle humain dans une production avec l'IA
```

Autre variante possible :

```text
Piloter, contrôler, corriger, valider, assumer : guide pratique pour produire avec l'IA
```

## 3. Cinq grandes parties possibles

### Partie 1 - Comprendre la place de l'IA

Objectif : expliquer simplement que l'IA est un assistant de production, pas un décideur.

Contenu possible :

- ce que l'IA peut aider à faire ;
- ce que l'IA ne doit pas décider seule ;
- pourquoi l'humain reste responsable du livrable.

### Partie 2 - Piloter la demande

Objectif : montrer comment formuler une consigne claire avant de demander une production à l'IA.

Contenu possible :

- préciser l'objectif ;
- donner le public cible ;
- indiquer le format attendu ;
- poser les limites à respecter.

### Partie 3 - Contrôler et corriger la réponse

Objectif : apprendre à relire une réponse IA avant de l'utiliser.

Contenu possible :

- vérifier si la réponse respecte la demande ;
- repérer les erreurs ou les oublis ;
- simplifier les formulations trop vagues ;
- adapter le texte au contexte réel.

### Partie 4 - Valider avant diffusion

Objectif : décider si le document est prêt ou s'il doit encore être amélioré.

Contenu possible :

- vérifier la clarté ;
- vérifier l'utilité pour le public cible ;
- éviter les promesses excessives ;
- confirmer que le document peut être utilisé en séance.

### Partie 5 - Assumer le livrable final

Objectif : rappeler que la personne qui remet ou publie le document reste responsable du résultat.

Contenu possible :

- expliquer ses choix ;
- corriger une erreur signalée ;
- citer clairement le rôle de l'IA si nécessaire ;
- garder une trace des étapes de production.
