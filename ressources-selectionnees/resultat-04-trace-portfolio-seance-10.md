## Preuve 10 - Fiche projet V1

**Date de la séance illustrée (exemple fictif) :** lundi 26 octobre 2026  
**Module :** 03 - Documents professionnels  
**Séance :** 10  
**Livrable :** `03-documents/fiche-projet-v1.md`  
**Statut :** V1 - À RELIRE  

---

### Ce que j'ai appris

J'ai appris à transformer une note de cadrage courte en fiche projet V1.  
J'ai compris qu'une fiche projet doit présenter clairement l'objectif, le public cible, le problème traité, la solution proposée, les livrables attendus et les prochaines étapes.  
J'ai aussi appris qu'un document produit avec l'aide de l'IA doit être relu, corrigé et validé par l'humain avant d'être utilisé.  

Dans cette séance, l'idée principale retenue est la suivante :

```text
L'IA assiste la production, mais l'humain garde la responsabilité du livrable final.
```

### Ce que j'ai produit

J'ai produit une fiche projet V1 sur le rôle de l'humain dans la production avec l'IA.

Cette fiche présente cinq responsabilités humaines :

1. piloter la demande ;
2. contrôler le contenu ;
3. corriger les erreurs ;
4. valider la version utile ;
5. assumer le livrable produit.

J'ai également préparé une évolution possible vers un guide pratique pour la séance 11.

### Ce que l'IA m'a aidé à faire

L'IA m'a aidé à :

- organiser les idées de la note de cadrage ;
- reformuler l'objectif du projet ;
- rendre le public cible plus visible ;
- clarifier le problème traité ;
- proposer une structure de fiche projet ;
- préparer un plan de guide pratique pour la suite.

L'IA n'a pas décidé à ma place. Elle a proposé une structure que je dois encore relire, ajuster et valider.

### Ce que j'ai vérifié moi-même

J'ai vérifié que :

- le sujet reste centré sur le rôle de l'humain dans la production IA ;
- le document ne présente pas l'IA comme un décideur ;
- les cinq responsabilités humaines sont bien présentes ;
- la prochaine action est concrète ;
- le statut reste `À RELIRE` et non `VALIDÉ`.

Points encore à vérifier :

```text
[ ] Les exemples sont-ils assez proches des situations vécues par les candidats ?
[ ] Le vocabulaire est-il adapté à un public débutant ?
[ ] Le format final doit-il être une fiche, un mini-guide Word ou un support de séance ?
[ ] Le document est-il assez court pour une utilisation en séance ?
```

### Prochaine action

Préparer le squelette du guide pratique de séance 11 à partir du plan produit, puis compléter une seule partie modèle pour montrer aux candidats comment passer du plan au contenu.
