## 1. Intention de la seance

La seance 10 transforme la note de cadrage courte en fiche projet V1.

Le candidat ne part plus seulement d'une idee.

Il apprend a organiser son intention sous forme de projet simple, lisible et realisable.

Message central :

```text
La note cadre l'idee.
La fiche projet rend l'action lisible.
```

La fiche projet sert a clarifier :

1. le nom du projet ;
2. l'objectif ;
3. le public cible ;
4. le probleme traite ;
5. la solution proposee ;
6. les livrables attendus ;
7. les etapes de production ;
8. la prochaine action.

---

## 2. Objectifs pedagogiques

A la fin de la seance, le candidat doit etre capable de :

1. expliquer le role d'une fiche projet ;
2. transformer une note de cadrage en projet structure ;
3. formuler un objectif simple et verifiable ;
4. identifier le public cible du projet ;
5. definir des livrables concrets ;
6. proposer des etapes realistes ;
7. utiliser l'IA pour structurer sans lui deleguer la decision ;
8. classer la fiche projet comme preuve de progression.

## 5. Mini-cours

Une fiche projet n'est pas une presentation longue.

C'est un document de pilotage simple.

Elle repond a trois questions :

```text
Qu'est-ce que je veux produire ?
Pour qui ?
Quelle est la prochaine action concrete ?
```

Une bonne fiche projet est :

- claire ;
- courte ;
- orientee action ;
- reliee a un besoin reel ;
- faisable avec les moyens disponibles ;
- utile pour preparer les livrables suivants.

Point de vigilance :

```text
L'IA peut proposer une structure.
Le candidat doit verifier la realite du projet.
```

---

## 6. Difference entre note de cadrage et fiche projet

| Note de cadrage | Fiche projet |
|---|---|
| Clarifie l'idee de depart | Organise l'action |
| Repond a "de quoi parle-t-on ?" | Repond a "que va-t-on produire ?" |
| Reste courte | Detaille les livrables et les etapes |
| Prepare la production | Sert a piloter la production |

Formule a retenir :

```text
La note de cadrage ouvre le chemin.
La fiche projet trace les premieres etapes.
```

## 8. Preparation en 5 questions

Avant d'utiliser l'IA, le candidat repond rapidement :

```text
1. Quel est le nom provisoire de mon projet ?
2. A qui ce projet va-t-il servir ?
3. Quel probleme ou besoin veut-il traiter ?
4. Quel livrable concret puis-je produire en premier ?
5. Quelle action puis-je faire cette semaine ?
```

Ces reponses doivent rester simples.

Si une reponse est floue, le candidat ecrit :

```text
A clarifier
```

## 10. Prompt de correction humaine guidee

```text
Relis ma fiche projet V1.

Ameliore-la selon ces criteres :
- objectif clair ;
- public cible visible ;
- probleme formule simplement ;
- solution realiste ;
- livrables concrets ;
- etapes faisables ;
- prochaine action precise ;
- absence de promesse excessive.

Contraintes :
- ne change pas mon intention principale ;
- ne rajoute pas d'informations incertaines ;
- signale les zones floues ;
- garde un format Markdown propre.

Format attendu :
1. version corrigee de la fiche projet ;
2. points a verifier par l'humain ;
3. checklist finale.
```

## 11. Exemple simple

```markdown
# Fiche projet V1

## Nom du projet
Guide d'organisation pour un soutien scolaire avec l'IA

## Objectif
Produire un guide court pour aider un enseignant ou un coach a organiser une premiere seance de soutien scolaire avec l'aide de l'IA.

## Public cible
Enseignants, formateurs, coachs scolaires et accompagnateurs debutants avec l'IA.

## Probleme traite
Beaucoup de personnes veulent utiliser l'IA pour aider les eleves, mais elles ne savent pas comment structurer une seance utile et controlee.

## Solution proposee
Creer un guide pratique qui explique comment definir l'objectif de la seance, preparer un prompt, produire une activite et verifier le resultat.

## Livrables attendus
- une fiche projet V1 ;
- un plan de guide pratique ;
- un guide pratique V1 ;
- une checklist de verification.

## Outils utiles
- ChatGPT ou un autre assistant IA ;
- un editeur Markdown ;
- un dossier candidat bien classe ;
- une checklist de validation humaine.

## Etapes de production
1. Relire la note de cadrage.
2. Identifier le public cible.
3. Lister les besoins principaux.
4. Construire le plan du guide.
5. Rediger une premiere version.
6. Relire et corriger.

## Criteres de reussite
- le guide est court ;
- le public comprend quoi faire ;
- les etapes sont realistes ;
- le role de l'humain reste visible ;
- le fichier est classe dans le bon dossier.

## Risques ou limites
- produire un document trop long ;
- laisser l'IA inventer des exemples non verifies ;
- oublier la relecture humaine ;
- confondre outil d'aide et decision pedagogique.

## Prochaine action
Preparer le plan du guide pratique pour la seance 11.

## Statut
V1 - A RELIRE
```
